# @vox-pilot/hands

MCP server for desktop input automation on Windows.

## What it provides

- Mouse actions: click, double click, right click, move, scroll
- Keyboard actions: Unicode typing, special keys, hotkeys
- Window/file actions: focus a window, open a path
- Compound actions: `perform_actions` for multi-step GUI flows in one PowerShell session

## Install

```bash
npx @vox-pilot/hands
```

## Example tools

- `mouse_click`
- `mouse_double_click`
- `mouse_right_click`
- `mouse_scroll`
- `mouse_move`
- `type_text`
- `press_key`
- `hotkey`
- `open_path`
- `focus_window`
- `perform_actions`

## Notes

- Windows only
- Optimized for AI agents that need reliable keyboard and mouse control
