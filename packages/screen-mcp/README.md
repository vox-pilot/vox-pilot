# @vox-pilot/screen

MCP server for screen observation on Windows.

## What it provides

- Full-screen screenshots
- Region screenshots
- Window listing
- Window details lookup

## Install

```bash
npx @vox-pilot/screen
```

## Example tools

- `screenshot`
- `screenshot_region`
- `list_windows`
- `get_window_info`

## Notes

- Windows only
- Intended for AI agents that need visual context from the desktop
